# 화면 상태 시안 — 여행 큐레이션

| 항목 | 내용 |
|---|---|
| 문서 | design/screen-states.md |
| 상태 | 입력 → 처리 중 → 결과 → 오류 (단일 페이지 흐름) |
| 기준 폭 | 모바일 **390px** · 데스크톱 **1440px** |
| 불변 규칙 | R4 — 두 폭의 입력 항목·선택지는 완전히 동일하다. **배치만 다르다** |

예시 데이터는 실제와 비슷한 길이로 채웠다. 글자 길이가 실제와 다르면 화면이 깨지는지 알 수 없다.

> 예시 시나리오: 제주도 · 2026.10.03–10.05(2박 3일) · 성인 2 아동 1 · 총 90만 원 · 힐링/자연/사진 · 해산물/현지식 · 고수 못 먹음 · 많이 걷기·사람 많은 곳 회피

## 0. 공통 레이아웃 규칙

| 항목 | 390px | 1440px |
|---|---|---|
| 좌우 거터 | 20px (`px-5`) | 32px (`sm:px-8`) |
| 콘텐츠 최대 폭 | 350px (= 390 − 40) | **1200px** (`max-w-[1200px]`). Hero 카피는 640px, 부제는 520px |
| 섹션 상하 여백 | 64px | 120px |
| 카드 내부 패딩 | 20px | 32px |
| 그리드 | 1열 고정 | 12열 / gap 24px |
| 터치 타깃 | 최소 44×44px | 최소 40×40px |
| 가로 스크롤 | **발생하지 않는다** (`document.body.scrollWidth <= 390`, S9) | — |

| z | 레이어 | 스크롤 진행률 0 → 1 거동 | 모바일 <768px | 모션 저감 |
|---|---|---|---|---|
| 0 | 배경 사진 시퀀스 | `scale 1→1.12` · `opacity 1→0.35` · `blur 0→6px` | 동일하게 전환 | **첫 장에서 정지** |
| **10** | **R3F Canvas** | 카메라 `z 6→3.2` · 그룹 `rotation.y 0→0.9` · 파티클 확산 `1→1.8` · 파티클 `opacity 0.5→0.06` | **마운트 안 함** | **마운트 안 함** |
| **20** | **두 겹 스크림** | **변화 없음 (opacity 1 고정)** | 동일 | 동일 |
| 30 | 카피 (h1/보조/CTA) | `y 0→-80px` · `opacity 1→0` | 이동 없음 | 이동 없음 |
| 40 | 스크롤 큐 | 진행률 0.15에 `opacity → 0` | 표시, 루프 없음 | 표시, 루프 없음 |

> **스크림(20)이 Canvas(10)보다 위다.** 처음에는 반대였고, 그 구성에서 흰 파티클이 카피 뒤 배경을 밝혀 텍스트 대비를 **9포인트 가까이** 깎았다. 파티클은 `Math.random()`으로 흩어지므로 대비가 **로드마다 달라지는 값**이었다. 근거는 [color-system.md](./color-system.md) §5-3.

**Hero pin**: `start: 'top top'` · `end: '+=120%'` · `scrub: 1` · `pin: true` · `anticipatePin: 1` — `full` 조건에서만.

## 8. 390px 가로 스크롤 방지 체크리스트 (S9)

| # | 위험 요소 | 대책 |
|---|---|---|
| 1 | 사용자 입력 여행지 40자 | `overflow-wrap: anywhere` + 부모 flex 자식에 `min-width: 0` |
| 2 | 예산표 4열 | 열 폭을 `%`로. 금액은 `tabular-nums`이되 줄바꿈 허용 |
| 3 | 긴 장소명 | `word-break: keep-all` + `overflow-wrap: anywhere` |
| 4 | 칩 그룹 | `flex-wrap: wrap`. 가로 스크롤 컨테이너를 만들지 않는다 |
| 5 | Hero 배경 사진 | `object-fit: cover` + `width: 100%`. 고정 폭 금지 |
| 6 | 확신도 배지 | 부모가 `inline-flex` + `flex-wrap: wrap`. 배지만 `nowrap` |
| 7 | 그림자 | `overflow-x: clip`을 `body`에 두지 않는다 — `position: sticky`가 깨진다. 요소별로 폭을 관리한다 |
