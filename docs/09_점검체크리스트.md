## 2. 코드 변경마다 — 로컬 게이트

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

4개 **전부** 통과해야 한다.

### 2-1. `build` 를 빼면 안 되는 이유

`build` 는 **`server-only` 경계 위반(SEC2/SEC3)을 잡는 유일한 스텝**이다.
`lint` 와 `typecheck` 는 클라이언트 컴포넌트가 `lib/env.ts` 를 import 해도
아무 말 없이 통과한다. 빌드만이 실패한다.

### 2-2. 각 스텝이 지키는 것

| 스텝 | 지키는 것 |
|---|---|
| `lint` | 3D 격리(가드레일 1) · 금액/시각 렌더링 계약(가드레일 2) |
| `typecheck` | 테스트 파일 포함 전체 타입 (`**/*.ts` 가 이미 포함한다) |
| `test` | 168건. 특히 `maxDepth ≤ 11` 단언과 프롬프트 펜스 격리 16건 |
| `build` | `server-only` 경계 · 정적 프리렌더 가능 여부 · First Load JS 수치 |

## 3. 배포 후마다 — 라이브 스모크

```bash
./scripts/check-live.sh                      # 기본: 프로덕션 별칭
./scripts/check-live.sh https://<배포-URL>   # 특정 배포 지정
```

스크립트가 확인하는 것:

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 공개 노출 | 공개 전까지 **302** (SSO). `200` 이면 **경고** |
| 2 | `X-Powered-By` | **0건** |
| 3 | 폰트 자체 호스팅 | `200` · `font/woff2` · **≤ 320 KB** |
| 4 | 폰트 캐시 | `immutable` 포함 |
| 5 | 리전 | `x-vercel-id` 가 `icn1` |
| 6 | 서버 검증 | 빈 본문 POST → **422** + 한국어 필드 오류 |
| 7 | 오류 응답 위생 | 스택 · 파일 경로 · 영문 Zod 메시지 **0건** |
| 8 | 보안 헤더 | CSP · X-Frame-Options · Referrer-Policy · X-Content-Type-Options 존재 여부 **보고** (현재 전부 없음 → §4 G1) |
| 9 | 레이트리밋 | 429 를 받으면 **PASS** — `lib/rate-limit.ts` 가 살아 있다는 증거 |

### 3-1. SKIP 은 실패가 아니다

| 상황 | 표시 | 뜻 |
|---|---|---|
| SSO 보호 중 | 6·7·8·불변식이 **SKIP** | 401 에 막힌 것. **그 자체가 "비공개"의 증거다** |
| 연달아 실행 | 6·7·불변식이 **SKIP** + 9번 **PASS** | **5회 / 10분** 한도에 걸렸다. `Retry-After` 초만큼 기다렸다 다시 돌린다 |

두 번째는 이 스크립트를 두 번만 돌려도 만난다. 결함이 아니라 설계대로다.

### 3-2. 로컬 프로덕션 빌드에 대해 돌리기

SSO 때문에 배포본에서는 본문 검사가 전부 SKIP 된다. 실제 판정을 보려면:

```bash
pnpm build
lsof -ti:3100 | xargs -r kill
PLAN_SOURCE=mock pnpm start -p 3100 &
./scripts/check-live.sh http://localhost:3100 --full
```

`next dev` 가 아니라 **반드시 `build && start`** 다 (§8).

## 4. 공개 전환 전 — 차단 게이트

> **하나라도 ❌ 면 전환하지 않는다.** 통과 표시는 날짜와 증거를 함께 남긴다.

| # | 항목 | 통과 기준 | 현재 | 근거 |
|---|---|---|---|---|
| **G1** | 보안 헤더 | CSP · X-Frame-Options · Referrer-Policy · X-Content-Type-Options 가 응답에 존재 | ❌ **전무** | `08` §4 #10 |
| **G2** | 레이트리밋 | 전역 한도를 확보했거나, "인스턴스별 한도"임을 **명시적으로 수용** | ❌ 미판단 | `08` §1 #4 · `07` §5 |
| **G3** | Node 런타임 | CI 와 Vercel 이 **같은 메이저**. `engines` 가 자동 상승을 막는다 | ❌ **22 vs 24** | `08` §4 #11 |
| **G4** | 키 노출 | `grep -rF "$GEMINI_API_KEY" .next/ \| wc -l` → **0**<br>`grep -roE "AIza[0-9A-Za-z_-]{35}" .next/ \| wc -l` → **0** | ✅ 재실행 필요 | `06` §3 SEC3 |
| **G5** | 실연동 QA | SEC8 · E3-S12 · S2 세 경로 판정 완료 | ❌ 할당량 | `08` §1 #1~3 |
| **G6** | 오류 모니터링 | 드레인 · 에러 추적 · Analytics 중 **최소 1개** | ❌ 없음 | `08` §4 #14 |
| **G7** | 메타데이터 | `metadataBase` + OG 이미지 + `robots.ts` | ❌ 없음 | `08` §4 #12·13 |
| **G8** | 외부 요청 | 전체 브라우저 세션에서 외부 호스트 **0건** (SEC14) | ✅ 재실행 필요 | `06` §3 SEC14 |

### 4-1. 전환 절차

1. G1~G8 전부 ✅
2. `./scripts/check-live.sh` 전 항목 통과
3. Vercel Settings → Deployment Protection → `ssoProtection.deploymentType` 을
   `all` → `all_except_custom_domains` 또는 `preview`
4. **즉시** `./scripts/check-live.sh` 재실행 — 이번엔 1번이 `200` 이어야 하고
   6·7·8 이 SKIP 이 아니라 실제 판정을 내야 한다
5. `07_배포.md` §4 에 전환 일시와 결과 추가

### 4-2. 되돌리는 법

```
ssoProtection.deploymentType → "all"
```
설정 한 곳이다. 빌드 산출물은 영향받지 않는다.

## 5. 재측정 트리거 — 무엇을 건드리면 무엇이 무효가 되는가

> 이 표가 이 문서의 핵심이다. **측정은 입력이 바뀌면 조용히 거짓이 된다.**
> 문서에 숫자가 남아 있다는 사실이 그 숫자가 아직 참이라는 뜻은 아니다.

| 이걸 수정하면 | 이 측정이 무효가 된다 | 재실행할 것 |
|---|---|---|
| **Hero 카피의 폭·크기·줄바꿈**<br>(`max-w-[640px]` · `max-w-[520px]` · `text-display-responsive`) | **Hero 대비 15개 값** | `design/color-system.md` §5-1 의 4단계를 **3D 구동 상태 + 사진 3장 전부**에 대해. eyebrow / h1 / 부제 / CTA 보조 / SCROLL 5개.<br>**여유 +0.3 미만이면 불통과.** 해법 순서: 전경 알파 상향 → 수평 stop 알파 상향.<br>**z 순서(스크림 z=20 > 캔버스 z=10)는 절대 건드리지 않는다** |
| **폰트 파일 · `unicode-range`** | Hero 대비 · CLS · 폰트 예산 | 위 전부 + CLS 재측정 + `ls -l public/fonts/*.woff2` ≤ 320 KB + 외부 폰트 요청 0건.<br>파일명을 바꾸지 않으면 `immutable` 헤더 때문에 **구 폰트가 캐시에 남는다** |
| `lib/validation/itinerary-schema.ts` 의 중첩 깊이 | `maxDepth` 단언 | `pnpm audit:schema` → `maxDepth ≤ 11`. 넘으면 Gemini 거부가 폴백으로도 안 풀릴 수 있다 |
| `lib/gemini/normalize.ts` 의 산술 | **R8 불변식 전부** | §6 불변식 검증. Σ행=총계 · Σ일자소계 · 비중 합 **정확히 100.0** |
| `next/dynamic` 경계 · GSAP import 위치 | First Load JS **197 kB** | `pnpm analyze` → `gsap/Flip` 과 `components/result/*` 가 **초기 청크가 아닌지** + `pnpm build` 의 `/` 라인 |
| `components/three/**` **밖으로** three import 이동 | 3D 격리(가드레일 1) | `pnpm lint` 가 잡는다. `pnpm analyze` 로 재확인 — 새면 3D 청크가 초기 번들로 끌려온다 |
| `total`·`cost`·`estimate`·`perPerson` 이름의 **지역변수 추가** | 금액 렌더링 계약(가드레일 2) | `pnpm lint`. 이 규칙은 **식별자 이름 기반**이라 안전한 값도 이름 때문에 걸린다 |
| `PlanExperience.tsx` 의 렌더 구조 | 포커스 트랩 · 390px 가로 스크롤 | 입력/로딩/결과/오류 **4개 상태 전부** `document.body.scrollWidth <= 390` + 오버레이에서 Tab 10회에 탈출 0 |
| `lib/state/plan-machine.ts` 의 전이 | `submitting` / `busy` prop 발화 | 제출 시 폼 버튼이 "만드는 중..." 회색 · [다시 만들기] 시 결과 버튼 회색 |
| `app/globals.css` 의 `:focus-visible` 위치 | 포커스 표시 | **`@layer base` 안으로 옮기면 Tailwind 유틸리티에 진다.** 최상위에 있어야 한다. 측정법은 §8 |
| `next.config.ts` 의 `headers()` | 캐시 · 보안 헤더 | `./scripts/check-live.sh` |
| `public/images/` 추가·삭제 | assets-manifest 대조(S18) | `ls public/images/ \| wc -l` == `assets` 배열 길이 + 푸터 §8 출처 목록 대조 |

## 6. 불변식 자동 검증

`./scripts/check-live.sh --full` 이 정상 요청 1건을 보내 아래를 전부 확인한다.

| 불변식 | 기준 | 근거 |
|---|---|---|
| R8 총계 | Σ `budget.lines[].estimate.amount` == `budget.total.amount` | 모델 산술 불신 |
| R8 범위 | Σ `rangeLow` == `total.rangeLow`, Σ `rangeHigh` == `total.rangeHigh` | 동일 |
| R8 일자 | 일자별 Σ `items[].cost.amount` == `daySubtotal.amount` | 동일 |
| 비중 | Σ `sharePercent` == **정확히 100.0** | 3×33.3 잔차 보정이 살아 있는가 |
| R1 | 응답 전체에 `confirmed` 문자열 **0건** | 확정 가격 금지 |
| R1 | `confidence` ⊆ `{estimate, typical_range, unverified}` | 3-값 유니온 |
| R5 | 좌표 패턴 `\d{2}\.\d{4,},\s*\d{2,3}\.\d{4,}` **0건** | 지도·좌표 금지 |
| S16 | `https?://` **0건** · 전화번호 패턴 **0건** | 예약·결제 동선 0 |
| 면책 | `disclaimers` 길이 **4** (저하 시 5) | 항상 붙는가 |
| 구조 | `days` ≥1 · `checklist.items` ≥6 · `rainyDay.alternatives` ≥2 | 최소 충족 |

> **실연동으로 전환한 직후 반드시 한 번 돌린다.** 목업은 고정 픽스처라
> 항상 통과하지만, 실연동은 모델 응답이 매번 다르고 R8 재계산이 실제로
> 일하는 유일한 경로다.

## 8. 측정할 때 반복해서 틀렸던 것

> QA 과정에서 **실제로 여러 번 잘못 측정한** 항목들이다.
> 잘못된 측정은 없는 결함을 만들고 있는 결함을 가린다.

| 함정 | 증상 | 올바른 방법 |
|---|---|---|
| `:focus-visible` ① | JS `.focus()` 로는 매칭되지 않는다 | **실제 Tab 키**를 보낸다 |
| `:focus-visible` ② | 창이 비활성이면 매칭되지 않는다 | `page.bringToFront()` 선행 |
| `:focus-visible` ③ | `transition` 이 걸린 요소는 **전이 시작값**이 읽힌다 | Tab 후 **~260ms 대기** 뒤 측정 |
| Hero 대비 | `prefers-reduced-motion: reduce` 가 남아 3D 가 꺼진 채로 측정됨 | `reducedMotion: 'no-preference'` 컨텍스트를 명시 |
| 포트 | `kill %1` 이 Bash 호출 간에 안 먹는다 (호출마다 새 셸) | `lsof -ti:PORT \| xargs -r kill` 선행 |
| 빌드 | `pnpm start` 가 EADDRINUSE 로 **조용히 실패**해 구버전을 테스트 | 기동 후 응답이 최신 커밋인지 확인 |
| 성능 | `next dev` 수치 사용 | 반드시 `pnpm build && pnpm start` |
| 성능 | 1회 측정 | **3회 median**. 모션 ON/OFF 양쪽 |
| 반응형 | 데스크톱만 확인 | **390px 에서만 렌더되는 마크업이 있다.** 확신도 배지 누락 결함이 여기서 나왔다 |
| 예외 화면 | `app/page.tsx` 에 `throw` 를 넣어 `error.tsx` 테스트 | 정적 프리렌더라 **빌드가 깨진다.** 하이드레이션 시점 조건부 throw 를 쓴다 |

## 9. 이 문서의 갱신 규칙

- §4 게이트를 통과시키면 **날짜와 증거(명령 출력 또는 커밋 해시)** 를 함께 적는다.
  ✅ 만 남기면 언제 무엇으로 확인했는지 알 수 없다.
- §5 에 행을 추가하는 기준: **어떤 값이 다른 파일의 내용에 의존하는가.**
  의존하면 트리거다.
- §8 은 줄이지 않는다. 같은 함정을 다시 밟는 비용이 문서 길이보다 크다.
